# 小紫流虎 公式ホームページ・ベース

## ファイル
- `index.html`：ページ本文
- `style.css`：色・配置・スマートフォン対応
- `script.js`：モバイルメニューと年表示
- `images/`：立ち絵や作品画像を入れるフォルダ

## ローカルで表示する
1. ZIPを展開します。
2. `index.html` をブラウザで開きます。
3. VS Codeで編集する場合は、フォルダごと開きます。

## 最初に変更する場所
1. `index.html` 内の紹介文を自分の言葉に調整。
2. Xのリンク `href="#"` を自分のプロフィールURLに変更。
3. メインイラストを `images/main.png` として保存し、HTML内の画像タグのコメントを外す。
4. ギャラリーの仮表示を作品画像に置き換える。

## メイン画像の入れ方
`images` フォルダに `main.png` を置き、`index.html` 内で次の行を探します。

`<!-- <img src="images/main.png" alt="小紫流虎のメインビジュアル"> -->`

コメント記号を外して、次のようにします。

`<img src="images/main.png" alt="小紫流虎のメインビジュアル">`

ギャラリー画像を追加する際は、`gallery-placeholder` の部分を `<img src="images/作品ファイル名.png" alt="作品の説明">` に置き換え、必要に応じてCSSで表示サイズを調整してください。

## 公開時の注意
- 画像の掲載許可やクレジット表記を確認してください。
- 個人の住所・電話番号など公開したくない情報を載せないでください。
- YouTubeやXなどのリンクが正しいことを公開前に確認してください。
- このひな形にはバックエンド、ログイン、問い合わせフォーム送信機能はありません。
